TSP：¶

Problem Description¶

You, a clever post-apocalyptic survivor, have just successfully used quantum algorithms in an abandoned warehouse to find a supply combination that maximizes value. Now, your next challenge has arrived: you need to transport these precious supplies safely back to headquarters.

However, your supply vehicle has limited fuel. To maximize efficiency and save every drop of fuel, you must plan the shortest possible tour route. This route must start from headquarters, sequentially visit 9 outposts to distribute supplies, and finally return to headquarters, ensuring that each outpost is visited only once.

This is the well-known Traveling Salesman Problem (Traveling Salesman Problem, TSP). We will use two algorithms to assist your decision-making:

Simulated Annealing (Simulated Annealing, SA)

Quantum-Inspired Simulated Annealing (Quantum-Inspired Simulated Annealing, SQA)

Converting the TSP Problem into a QUBO Model¶

We use binary variables x_i,t to represent “visiting outpost i at time step t”.

Our objective is to minimize the total path length, while satisfying two strict constraints:

Each outpost must be visited exactly once.

At each time step, only one outpost can be visited.

Therefore, the QUBO objective function can be written as:

$ \begin{aligned} H(x)\;=\;&\underbrace{\sum_{i=1}^N\sum_{\substack{j=1\\j\neq i}}^N\sum_{t=1}^N d_{ij}\;x_{i,t}\,x_{j,t+1}}_{\text{(1) Minimizing the total path length}}\\ &+\;P\;\underbrace{\sum_{i=1}^N\Bigl(\sum_{t=1}^N x_{i,t} - 1\Bigr)^{2}}_{\text{(2) Each outpost is visited exactly once}}\\ &+\;P\;\underbrace{\sum_{t=1}^N\Bigl(\sum_{i=1}^N x_{i,t} - 1\Bigr)^{2}}_{\text{(3) Only one outpost is visited at each time step}} \end{aligned} $

$ • x_{i,t}\in\{0,1\} indicates “whether outpost i is visited at time slot t”. $

$ • d_{ij} is the distance from outpost i to outpost j, and the index t+1 is handled with modulo N to form a closed loop. $

$ • P (penalty in the code) is the penalty coefficient, which should be chosen to be larger than the total sum of all distances to ensure that the constraints are strictly enforced. $

After expansion:

Each outpost is visited exactly once $ P\sum_{t=1}^{N}\bigl(\sum_{i}x_{i,t}-1\bigr)^{2} = P\sum_{t=1}^{N}\Bigl[ -\sum_{i=1}^{N}x_{i,t} +2\sum_{1\le i<i’\le N}x_{i,t}\,x_{i’,t} +1\Bigr]. $

At each time step, exactly one outpost is visited $ P\sum_{t=1}^{N}\bigl(\sum_{i}x_{i,t}-1\bigr)^{2} = P\sum_{t=1}^{N}\Bigl[ -\sum_{i=1}^{N}x_{i,t} +2\sum_{1\le i<i’\le N}x_{i,t}\,x_{i’,t} +1\Bigr]. $

# 3. Construct the QUBO model

penalty = 200
Q = {}
N = num_cities

# Objective function term: minimize the total path length
for i in range(N):              # for each departure outpost i
  for j in range(N):            #   for each arrival outpost j
    for t in range(N):          #     for each time slice t
      t_plus_1 = (t + 1) % N    #     next time slice (cyclic)
      if i != j:
        # Transition between different outposts i→j: place distance d_ij into Q[(u,v)]
        Q[(i*N + t, j*N + t_plus_1)] = distance_matrix[i,j]
      else:
        # If i == j, this represents “the same outpost from the same time to the next time”,
        # and this quadratic term should be set to 0
        Q[(i*N + t, j*N + t_plus_1)] = 0

# Constraint 1: each outpost is visited exactly once
for i in range(N):              # for each outpost i
  for t1 in range(N):           #   for all time slots t1 of this outpost
    # Linear term (diagonal term): add penalty * (-1)
    Q[(i*N + t1, i*N + t1)] = Q.get((i*N + t1, i*N + t1), 0) + penalty * (-1)

    for t2 in range(t1+1, N):  #   for different times t1 < t2 of the same outpost
      # Interaction term (quadratic term): add penalty * 2
      Q[(i*N + t1, i*N + t2)] = Q.get((i*N + t1, i*N + t2), 0) + penalty * 2

# Constraint 2: exactly one outpost is visited at each time step
for t in range(N):              # for each time slice t
  for i1 in range(N):           #   for all outposts i1
    # Linear term (diagonal term): add penalty * (-1)
    Q[(i1*N + t, i1*N + t)] = Q.get((i1*N + t, i1*N + t), 0) + penalty * (-1)

    for i2 in range(i1+1, N):   #   for different outposts i1 < i2 at the same time
      # Interaction term (quadratic term): add penalty * 2
      Q[(i1*N + t, i2*N + t)] = Q.get((i1*N + t, i2*N + t), 0) + penalty * 2

Part I: Using Simulated Annealing (Simulated Annealing, SA)¶

SA is a heuristic algorithm based on the physical annealing process. Imagine a piece of metal that is heated and then gradually cooled; its molecules slowly transition from a random arrangement toward an ordered crystalline structure, eventually reaching a stable state with minimum energy. SA mimics this process: it starts from a random solution, and at a higher “temperature”, it accepts worse solutions (higher energy) with a certain probability, which helps the algorithm escape the trap of local optima. As the “temperature” gradually decreases, the probability of accepting worse solutions also decreases, and the algorithm eventually converges to a better solution.

sampler_sa = dimod.SimulatedAnnealingSampler()
sampleset_sa = sampler_sa.sample_qubo(
    Q,
    num_reads=100  # number of independent samples

best_solution_sa = sampleset_sa.first.sample

    for t in range(N):
        if best_solution_sa.get(i * N + t) == 1:
            path_sa.append((t, names[i]))

# Sort by time and close the tour
path_sa.sort(key=lambda x: x[0])
final_path_sa = [city for _, city in path_sa]
final_path_sa.append(final_path_sa[0])

# Compute the total distance
total_distance_sa = 0.0
for t in range(N):
    from_city = path_sa[t][1]
    to_city   = path_sa[(t + 1) % N][1]
    i = names.index(from_city)
    j = names.index(to_city)
    total_distance_sa += distance_matrix[i, j]

Part II: Using Quantum-Inspired Simulated Annealing (SQA) - Time-Slicing Method¶

In classical Simulated Annealing (SA), the algorithm relies solely on “thermal fluctuations” to cross energy barriers, and it often becomes trapped in local minima within complex energy landscapes. Quantum-Inspired Simulated Annealing (SQA), in contrast, employs “imaginary-time slicing” and “transverse-field coupling” to replicate each variable into multiple copies, and uses the Path-Integral Monte Carlo (PIMC) method to simulate quantum tunneling processes. This approach is equivalent to creating a “shortcut” in the energy landscape, allowing the system to probabilistically pass through steep energy barriers and rapidly escape local traps. Therefore, in multimodal or high-dimensional combinatorial optimization problems, SQA is more capable than traditional SA of exploring the global minimum.
