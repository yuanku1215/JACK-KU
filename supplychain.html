Learning Overview

This portfolio consolidates modeling exercises into a consistent IEOR workflow: define decision variables, implement clean objective functions, encode real operational logic as constraints, and iterate with diagnosis when infeasibility or degeneracy occurs. I treat each file as a reusable template rather than a one off homework solution.

Key outcome: I can rapidly move from qualitative descriptions to rigorous formulations, while understanding how formulation choices affect solver behavior, integrality, and stability.

Modeling Competency for IEOR

I build optimization models from real operational narratives. I design decision variables, objectives, and constraints with clear indexing and logic, then debug infeasibility and strengthen formulations based on solver feedback.

What I can do

Formulate LP and MILP models, encode logical constraints, and implement standard OR patterns such as transportation, assignment, set covering, max flow, shortest path, precedence constraints, and scenario based evaluation.

Why it is relevant

These artifacts demonstrate rigorous formulation skills and disciplined debugging. The same modeling patterns transfer directly to Python modeling stacks such as Pyomo, PuLP, and OR Tools for research and reproducible experimentation.

How I work

I treat each model as a reusable template. My focus is not only solving, but also making assumptions explicit, keeping constraints consistent, and ensuring the formulation is stable and interpretable.
