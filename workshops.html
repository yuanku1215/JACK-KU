Overview

This workshop is organized around an optimization first learning path. The narrative starts from NP hard combinatorial problems and simulated annealing, then introduces quantum concepts needed for quantum annealing, and proceeds to practical QUBO modeling and simulated quantum annealing. The second half focuses on execution workflows, including how to run experiments on Taiwania 3 with Slurm and how to scale code using modular scripts.

Scope boundary: I focused on the modeling workflow and how to run and validate experiments. Physics details are introduced only as needed to explain the algorithmic behavior and representations.

What I Covered

Origins and motivation

Problem definition for NP hard optimization and why search becomes difficult as the solution space grows.

Core mathematical representations

Hamiltonian viewpoint and the mapping choices between Ising and QUBO for executable models.

Simulated Quantum Annealing

SQA as a classical simulation of quantum annealing behavior using Path Integral Monte Carlo and time slicing.

HPC execution on Taiwania 3

Linux workflow, Slurm batch scripts, environment modules, and modular program structure for scaling runs.

Code walkthrough and demos

Step by step code explanation, sanity checks, and how to debug indexing, penalties, and energy correctness.

Extension toward routing

From TSP formulation toward VRP style constraints and problem variants as an extension direction.

Workshop Structure

The structure follows the chapter layout of the slide deck, from problem definition through SA, quantum concepts, QUBO modeling, SQA, Taiwania 3 workflows, and demos including a routing extension.

Chapter based outline
  • Chapter 1: Defining the problem and NP hard examples such as TSP, VRP, and knapsack.
  • Chapter 2: Simulated annealing and core acceptance model.
  • Chapter 3 and 4: Quantum concepts, Hamiltonian, Ising versus QUBO, and penalty techniques.
  • Chapter 5: SQA core model including time slicing and Path Integral Monte Carlo.
  • Chapter 6: Taiwania 3 usage and recommended modular program structure.
  • Chapter 7 to 9: D Wave demos, custom QUBO application from TSP to VRP, and real world demo.

HPC Workflow Highlights

For Taiwania 3, I introduced the minimum set of operational steps: uploading files, verifying environments, writing Slurm scripts, submitting jobs, monitoring logs, and downloading results. I also explained why single script workflows often need refactoring into a task list plus worker scripts for large scale runs.
